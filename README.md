BioDefense Intelligence Division is a cyber-biosecurity intelligence and investigative forensics platform built with Python and C#. It is structured around federal-style case management, digital evidence acquisition and reconstruction, evidentiary correlation, chain-of-custody control, threat assessment, and intelligence production for cyber-enabled incidents affecting biomedical research, pharmaceutical laboratories, operational technology, connected medical systems, and critical infrastructure.

The platform maintains persistent investigations across scheduled GitHub Actions executions, preserves case and evidence continuity, evaluates correlated findings through a canonical C#/.NET threat-scoring engine, and produces synchronized forensic and intelligence records in JSON, XML, Markdown, CSV, and Excel. A read-only state-driven dashboard reflects the active case without altering authoritative investigation state.
